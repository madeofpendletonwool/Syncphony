# ADR 0009: nugs.net provider

- **Status:** accepted
- **Date:** 2026-10-06

## Context

nugs.net streams live concert recordings, mostly from bands with long histories of taped shows (Phish, the Grateful Dead's offshoots, Billy Strings). Some friends subscribe to it, and it has music no other service has.

nugs.net has no public API. Its apps use a private one, which other open-source clients ([Music Assistant](https://www.music-assistant.io/music-providers/nugs/), several downloaders) have documented by use. What we found, checked against the live catalog:

- **The catalog needs no account.** Search (`streamapi.nugs.net/api.aspx?method=catalog.search`), an artist's shows (`catalog.containersAll`) and show details (`catalog.nugs.net/api/v1/shows/{id}`) answer anonymous requests. A show that doesn't exist is a 204.
- **Search groups results by what they matched:** an artist, a song title, a venue, or an album. A song match lists every performance, each a track on a show, with the show's date and venue but no duration. Searching "tweezer" finds dozens of nights.
- **There is no track lookup.** A track ID alone can't be resolved; only its show can be fetched, and the show's details have each track's title and length.
- **Signing in** is an OpenID Connect password grant at `id.nugs.net`, with the apps' client ID. Asking for `offline_access` returns a refresh token, which rotates on use.
- **Streams** come from `bigriver/subPlayer.aspx`, which takes the track, the account's user ID and its subscription's IDs and dates, and a platform ID. Each platform answers with a signed URL to one format, recognized by its path: 16-bit FLAC, ALAC, MQA, AAC, 360 Reality Audio, or HLS. Some tracks are HLS only: AAC in MPEG-TS, AES-128 encrypted with a key the playlist links to.

## Decision

**Add a `nugs` stream provider**, on by default; `SYNCPHONY_NUGS=false` turns it off.

**Shows are albums, titled by date and venue** ("2024-12-31 · Madison Square Garden, New York, NY"), so a search's many performances of a song can be told apart. Albums keep their own titles. A track's ID is `<show>.<track>`, so `Track` can fetch its show. Search fetches the shows on the page it returns (six at a time) for durations; shows are cached for an hour, shared by every session, since the catalog is the same for everyone. Ranking puts exact song matches first, then prefix matches, newest performance first within each. An artist's page lists their 100 most recent shows.

**Store the refresh token, not the password.** Linking signs in once, and refuses accounts with no active subscription. A link's sessions share one set of tokens, so they don't spend the same refresh token twice; rotated tokens are saved through the credential sink. A refresh token nugs.net refuses means the link has expired.

**Pick the format by the player.** Stream asks every platform for its URL and plays FLAC (or MQA, which plays as FLAC) if the player takes it, else AAC, else ALAC; under a bitrate cap below 1,000 kbit/s, AAC first. If the player takes none, the best goes to the server's transcoder. Files are proxied with range requests intact. HLS-only tracks are read segment by segment, decrypted, and passed on as MPEG-TS, which the transcoder converts; they can't seek. 360 Reality Audio is never chosen.

**Refuse what won't play when it's added.** Sessions implement `PlayChecker`: a show that's sold but not in the subscription catalog, or an account whose subscription has lapsed, is `ErrNotPlayable`.

Not shared (`Shareable: false`): it's a personal subscription. No playlists, lyrics, ISRCs or recommendations for now.

## Consequences

- It can break without notice: nugs.net owes third-party clients nothing, and using its private API is against its terms. Each friend uses their own account, as with Spotify (ADR 0004).
- Cross-service matching (ADR 0006) won't find nugs.net tracks elsewhere, and vice versa: live recordings have no ISRCs and rarely match studio versions.
- The provider's tests run the conformance suite against a fake nugs.net, and decode payloads captured from the real one. `TestConformanceLive` runs it against nugs.net when `SYNCPHONY_TEST_NUGS_EMAIL` and `SYNCPHONY_TEST_NUGS_PASSWORD` are set. Streaming has only been tested against the fake.
